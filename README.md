A tiny Python program that writes one haiku about debugging — three lines in the 5-7-5 syllable shape, 67 characters — to `/output/entry.txt` for make.fun's Seventeen Syllables of Debugging bounty.

```
red line in the log
three a.m. cursor blinks, waits
it was my typo
```

A red line in the log, a cursor blinking at three in the morning — and the turn in the last line: after a night of hunting, the bug was the author's own typo.

## Run it

```sh
python3 main.py
```
